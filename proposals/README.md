# Proposed instincts

The instinct reviewer writes draft instincts here: one file per proposal, with the reflex, the miss, the question and the proof. The developer approves each one before it's added to the end of DEV-INSTINCTS.md.

Approved drafts stay here for their evidence. Each approved heading names its number in `DEV-INSTINCTS.md`, and its findings carry that number instead of the `proposed:` tag. Provisional labels (F1–F14, L1–L12, D1–D6) are never instinct numbers.
